# film-coach

アメリカンフットボールの選手動画を分析し、改善点をレポートするシステム。

**自分専用の AI フィルムルーム** — QB の投球動作を骨格レベルで分解し、自己ベストと YouTube から集めたお手本の両方と比べて、「何がどれだけずれているか」を根拠のフレームと練習ドリルを添えて示します。

**デモ**：https://motoharuinoue.github.io/film-coach/ （仮データで動きます。サーバーは不要）

## 特徴

- **2 つの基準**：自己ベスト・レップ間のばらつきと、重み付けしたお手本の分布の両方で判定する
- **重み付けの根拠を全部見せる**：お手本 1 本ごとに、人気度・発信者・解析品質・合意度・手動調整の内訳を表示する
- **ローカル処理**：解析も LLM も手元の Mac で動かす
- **数値をでっち上げないレポート**：判定はルールエンジン、LLM は文章化だけ

## 画面（M0、仮データ）

画面は「使う流れ」の 4 段階にまとめています。初めて開くと、使い方ツアーが主な画面を順に案内します。

| 段階 | 画面 | 内容 |
|---|---|---|
| — | ホーム | 最新セッションのスコア、次に直すこと、主要指標の推移、最近のセッション |
| ① 取り込む | 新規セッション | ファイルか YouTube URL（区間指定）で取り込み、撮影角度で測れる指標を事前に表示、解析の進み具合 |
| ① 取り込む | レップ選択 | 自動で切り出したレップの一覧、試合映像での対象選手のロック |
| ② 見る | 分析スタジオ | 骨格・角度・手首の軌跡・ゴーストの重ね表示、フェーズのタイムライン、コマ送り、同期グラフ、指標カード。「比較」に切り替えると自己ベストかお手本と重ねて・並べて比べる |
| ③ 直す | レポート | スコアとレーダー、改善点トップ 3 とドリル動画、良かった点、リリース点の一貫性、出典。PDF に出力 |
| ④ 続ける | 推移 | セッションごとの平均と幅、お手本ゾーン、指標ごとの自己ベスト |
| 判定の基準 | お手本ライブラリ | お手本の一覧、重みの内訳（P・C・Q・K・M）、手動調整、重み付き分布と人気度だけの場合の比較 |

## 開発

Node 22.12 以上と npm 11 以上を使います（npm 10 には、この依存関係の解決で失敗する不具合があります）。

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ユニットテストと、依存の向き（層のルール）の検査
npm run build
```

`master` に入ると、GitHub Actions がテストとビルドを通したうえで GitHub Pages にデモを公開します（`.github/workflows/pages.yml`）。Pull Request では型検査・テスト・ビルドを実行します（`.github/workflows/ci.yml`）。

解析サービス（Python）は `services/analyzer` で動かします（詳しくは [services/analyzer/README.md](services/analyzer/README.md)）。

```bash
cd services/analyzer
uv sync
uv run pytest        # TypeScript と同じ結果になることの確認を含む
uv run lint-imports  # 層のルールの検査
```

### 自分の映像を解析する（手元だけ）

解析サービスを起動してから画面を開くと、サイドバーの「自分の映像」が使えます（公開デモでは使えません。映像は手元から外に出しません）。

```bash
cd services/analyzer
uv run film-coach models download   # 初回だけ（約 145 MB）
uv run film-coach serve             # http://127.0.0.1:8787
# 別のターミナルで
npm run dev                          # http://localhost:5173
```

1. 「① 取り込む」でファイルか YouTube の区間を取り込む
2. フレームの上で本人を押して選ぶ
3. 追跡が終わったら、実際の映像に骨格を重ねて見る（フォーカス表示で本人を追って拡大）
4. 身長を入れて「投球を見つける」と、1 球ずつフェーズ（ドロップ〜フォロー）と QB 指標が出る。投球を選ぶとリリースの瞬間へ移る（横から全身を撮った映像が向いている。身長はブラウザの中にだけ保存する）
5. 「自分の映像」の「練習にまとめる」で何本かの映像を選ぶと、練習の画面で投球を並べて比べられる（指標のばらつき、リリース点の散らばり、リリースの骨格の重ね表示）

M0 では、骨格は合成データ（`apps/web/src/infrastructure/demo/synth.ts`）です。フェーズ分割・指標・重み付けは、実データと同じ計算を通しています。選手・チャンネル・動画はすべて架空です。
