# film-coach

アメリカンフットボールの選手動画を分析し、改善点をレポートするシステム。

**自分専用の AI フィルムルーム** — QB の投球動作を骨格レベルで分解し、自己ベストと YouTube から集めたお手本の両方と比べて、「何がどれだけずれているか」を根拠のフレームと練習ドリルを添えて示します。

## 特徴

- **2 つの基準**：自己ベスト・レップ間のばらつきと、重み付けしたお手本の分布の両方で判定する
- **重み付けの根拠を全部見せる**：お手本 1 本ごとに、人気度・発信者・解析品質・合意度・手動調整の内訳を表示する
- **ローカル処理**：解析も LLM も手元の Mac で動かす
- **数値をでっち上げないレポート**：判定はルールエンジン、LLM は文章化だけ
