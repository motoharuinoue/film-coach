# film-coach

アメリカンフットボールの選手動画を分析し、改善点をレポートするシステム。

**自分専用の AI フィルムルーム** — QB の投球動作を骨格レベルで分解し、自己ベストと YouTube から集めたお手本の両方と比べて、「何がどれだけずれているか」を根拠のフレームと練習ドリルを添えて示します。

**デモ**：https://motoharuinoue.github.io/film-coach/ （仮データで動きます。サーバーは不要）

## 特徴

- **2 つの基準**：自己ベスト・レップ間のばらつきと、重み付けしたお手本の分布の両方で判定する
- **重み付けの根拠を全部見せる**：お手本 1 本ごとに、人気度・発信者・解析品質・合意度・手動調整の内訳を表示する
- **ローカル処理**：解析も LLM も手元の Mac で動かす
- **数値をでっち上げないレポート**：判定はルールエンジン、LLM は文章化だけ

## 画面（M0、仮データ）

| 画面 | 内容 |
|---|---|
| ホーム | 最新セッションのスコア、次に直すこと、主要指標の推移、最近のセッション |
| 新規セッション | ファイルか YouTube URL（区間指定）で取り込み、撮影角度で測れる指標を事前に表示、解析の進み具合 |
| レップ選択 | 自動で切り出したレップの一覧、試合映像での対象選手のロック |
| 分析スタジオ | 骨格・角度・手首の軌跡・ゴーストの重ね表示、フェーズのタイムライン、コマ送り、同期グラフ、指標カード |
| お手本ライブラリ | お手本の一覧、重みの内訳（P・C・Q・K・M）、手動調整、重み付き分布と人気度だけの場合の比較 |
| 比較 | 自己ベストかお手本と、重ねて・並べて比べる。指標の差 |
| レポート | スコアとレーダー、改善点トップ 3 とドリル動画、良かった点、リリース点の一貫性、出典。PDF に出力 |
| 推移 | セッションごとの平均と幅、お手本ゾーン、指標ごとの自己ベスト |

## 開発

Node 22.12 以上と npm 11 以上を使います（npm 10 には、この依存関係の解決で失敗する不具合があります）。

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ユニットテストと、依存の向き（層のルール）の検査
npm run build
```

`master` に入ると、GitHub Actions がテストとビルドを通したうえで GitHub Pages にデモを公開します（`.github/workflows/pages.yml`）。Pull Request では型検査・テスト・ビルドを実行します（`.github/workflows/ci.yml`）。

M0 では、骨格は合成データ（`apps/web/src/infrastructure/demo/synth.ts`）です。フェーズ分割・指標・重み付けは、実データと同じ計算を通しています。選手・チャンネル・動画はすべて架空です。
