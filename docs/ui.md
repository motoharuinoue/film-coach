# UI 設計

## 1. デザイン言語

ダーク基調の「フィルムルーム」。映像が主役になるよう、周りの UI は暗く静かにし、骨格線と数値だけを光らせる。

### 1.1 カラー

| 用途 | 名前 | 値 |
|---|---|---|
| 背景 | Ink | `#07090D` |
| パネル | Panel | `#0E131A` |
| 上位パネル | Panel raised | `#141A23` |
| 境界線 | Line | `rgba(255,255,255,0.08)` |
| 本文 | Text | `#E8EDF2` |
| 補助テキスト | Text muted | `#8A96A3` |
| 良好・自分の骨格 | Turf | `#2EE59D` |
| 注目・再生位置 | Pylon | `#FF7A1A` |
| お手本・お手本ゾーン | Ice | `#5AC8FA` |
| 注意 | Caution | `#FFC24B` |
| 要改善 | Flag | `#FF4D5E` |

- フェーズは Turf の濃淡で時間の進みを表す（ドロップが最も淡く、フォロースルーが最も濃い）。
- 状態は色だけでなく、アイコン（チェック・三角・丸）でも示す。

### 1.2 タイポグラフィ

| 用途 | フォント |
|---|---|
| 本文・見出し | Inter + Noto Sans JP |
| 大きな数字 | Barlow Condensed |
| タイムコード・数値表 | JetBrains Mono |

いずれも SIL Open Font License。

### 1.3 動き

- Framer Motion で数値のカウントアップ、画面遷移、骨格の描画アニメーションを付ける。
- `prefers-reduced-motion` が有効なら動きを止める（`MotionConfig reducedMotion="user"`）。

### 1.4 印刷

レポート画面だけは、印刷用にライトテーマを用意する。

## 2. 使う流れと画面

機能が多くても迷わないよう、画面を「使う流れ」の 4 段階にまとめる。サイドバーもこの順に番号付きで並べ、いまどの段階にいるかを示す。

| 段階 | 画面 | パス | 役割 |
|---|---|---|---|
| — | ホーム（ロッカールーム） | `/` | 現状と次にやることを一目で見る |
| ① 取り込む | 新規セッション | `/sessions/new` | ファイルか YouTube URL で取り込む |
| ① 取り込む | レップ選択・対象ロック | `/sessions/:id/reps` | 解析結果から見たいレップを選ぶ。試合映像では対象選手を決める |
| ② 見る | 分析スタジオ（分析／比較） | `/sessions/:id/studio`（比較は `?view=compare`） | 1 レップを骨格レベルで見る（中心画面）。比較に切り替えると自己ベストかお手本と並べる |
| ③ 直す | レポート | `/sessions/:id/report` | 改善点とドリルを読む・出力する |
| ④ 続ける | 推移 | `/progress` | 指標の時系列を見る |
| 判定の基準 | お手本ライブラリ | `/references` | YouTube のお手本を集め、重みを確認・調整する |
| ① 取り込む | 自分の映像 | `/footage` | 手元の解析サービスに取り込んだ実際の映像の一覧（M1-3） |
| ① 取り込む | 本人を選ぶ | `/footage/:id/pick` | フレームの上で本人を 1 回押して選び、追跡を始める。進み具合を表示する |
| ② 見る | 映像を見る | `/footage/:id` | 実際の映像に、本人の枠と骨格を重ねて再生する。フォーカス表示で本人を追って拡大する |

「自分の映像」の 3 画面は、解析サービス（`services/analyzer`）につながっているときだけ使える。公開デモ（解析サービスなし）では、手元で動かす方法を案内する。サイドバーの「自分の映像」の横の点で、つながっているか（緑）、つながっていないか（赤）を示す。

旧 URL の `/sessions/:id/compare` は、分析スタジオの比較表示へ転送する。

### 2.1 使い方の案内

| 仕組み | 内容 |
|---|---|
| この画面でできること | 各画面の上に、目的（1 文）・主な操作（2〜3 個）・次に進む先を出す。閉じると「この画面の使い方」ボタンだけになり、閉じた状態はブラウザに保存する。文言は `presentation/guide/content.ts` にまとめる |
| 使い方ツアー | 初めてホームを開いたときに自動で始まる。8 ステップで、ホーム・分析スタジオ・レポート・お手本ライブラリの見るべき場所を光らせて説明する。サイドバーの「使い方ツアー」からいつでも見直せる。Esc で終了、← → で前後 |

## 3. 画面ごとの構成

### 3.1 ホーム（ロッカールーム）

- 選手カード：名前・背番号・身長・利き腕
- 総合スコアのリング（前回比）
- 「次に直すこと」カード：最優先の改善点 1 つと、おすすめドリル
- 主要指標のスパークライン（直近のセッション）
- 最近のセッションの一覧（サムネイル・種別・スコア）

### 3.2 新規セッション

1. 入力方法をタブで切り替える
   - **ファイル**：ドラッグ&ドロップ
   - **YouTube URL**：URL を貼る → 情報カード（タイトル・長さ・解像度）→ 区間指定のスライダー
2. 種別（ドリル／試合）とカメラ角度を指定する
3. 品質チェックの結果を表示する（使えない指標を事前に知らせる）
4. ★解析の進み具合をパイプライン図で表示する
   - 段階：正規化 → 検出 → 追跡 → 骨格 → 平滑化 → フェーズ → 指標 → 判定
   - 途中のフレームもプレビューする（SSE で更新）

### 3.3 レップ選択・対象ロック

- 自動で切り出したレップのサムネイル一覧（時刻・長さ・推定品質）
- 試合映像では選手をタップすると、SAM 2 のマスクがプレビューされる

### 3.4 分析スタジオ（中心画面）

```
┌─────────────────────────────┬───────────────┐
│ 動画 + オーバーレイ             │ 指標カード      │
│  骨格 / 角度の円弧 / 手首の軌跡  │  自分 / ベスト  │
│  ゴースト / 俯瞰図              │  / お手本       │
├─────────────────────────────┴───────────────┤
│ フェーズのタイムライン  [ドロップ|セット|ステップ|リリース|フォロー] │
│ ▶ コマ送り 0.25x  ────●──────────────          │
├─────────────────────────────────────────────┤
│ 同期グラフ：キネマティックシーケンス・関節角度・お手本ゾーン │
├─────────────────────────────────────────────┤
│ AI コーチの一言（最優先の改善点）                     │
└─────────────────────────────────────────────┘
```

- オーバーレイの各レイヤーはチップで切り替える。
- 指標カードを押すと、その指標の根拠になったフレームへ移動する。
- 3D 骨格ビューアは折りたたみ式（M5 以降）。

### 3.5 お手本ライブラリ

- **探す**：検索とチャンネル登録 → 候補のカード
  - カードの表示：サムネイル・再生数・高評価率・登録者数・ライセンスのバッジ
- **取り込む**：埋め込みプレイヤーで区間を指定 → 解析 → 骨格プレビューと品質スコア → 採用／除外
- **重みの内訳**：P・C・Q・K・M を要素ごとの棒で並べ、最終的な重みと一緒に表示する。手動調整（ピン留め・除外・星評価）もここで行う
- **分布**：指標ごとにお手本の分布（ヒストグラム）と、自分の値の位置を表示する

### 3.6 比較

- ゴーストを重ねる表示と、左右に並べる表示を切り替える。
- 比べる相手は自己ベストかお手本から選ぶ。
- 差分の指標表。

### 3.7 レポート

雑誌風のレイアウトで、上から次の順に並べる。

1. ヒーロー画像（注釈付きの根拠フレーム）
2. 総合スコアとレーダーチャート
3. 改善点トップ 3（説明・目標値・ドリル動画）
4. 良かった点
5. 一貫性の散布図
6. 参照したお手本の出典一覧

PDF 出力と共有ボタンを置く。

### 3.8 推移

- 指標ごとの時系列とお手本ゾーンの帯
- 自己ベストの更新履歴
