# ADR-0006: お手本の重み付けを 5 つの要素の積にする

- 状態：採用
- 日付：2026-10-05

## 背景

YouTube のお手本を集めて「お手本ゾーン」（重み付き分布）を作る。高評価数だけで重み付けすると、次の問題が起きる。

- 人気はあるが癖の強いフォームに、分布が引っ張られる。
- 撮影角度が合わない動画からも、指標を拾ってしまう。
- 再生数の少ない動画は、高評価率がたまたま高く出やすい。

## 決定

お手本ごと・指標ごとに、次の式で重みを計算する。

```
w(お手本, 指標) = P × C × Q(指標) × K(指標) × M
```

| 要素 | 計算 |
|---|---|
| P（人気度） | 高評価率をベイズ平均で補正する。計算式は `(likes + m·事前平均) / (views + m)`。そこに `log10(views)` を掛けて 0〜1 に正規化する。低評価数は 2021 年以降公開されていないので使わない |
| C（チャンネル） | `log10(登録者数)` を 0〜1 に正規化する。登録した信頼チャンネルには加点する |
| Q（解析品質） | 関節検出の信頼度の平均 × カメラ角度がその指標に合っているか（合わなければ 0）× 解像度・fps の係数 |
| K（一致度：他のお手本との一致） | 重み付き中央値と MAD からロバスト z スコアを計算し、z が大きいほど重みを下げる |
| M（手動調整） | ピン留め（×1.5）、除外（×0）、星評価 |

## 実装（M2-2）

- 重みと分布の計算は画面（`apps/web/src/domain/weighting.ts`）に 1 か所だけ置き、デモの合成データと手元のお手本の両方に同じ計算を通す
- 手元のお手本（`reference.v1`、`data/references/`）は、材料（登録したときに取り直した YouTube の統計・信頼チャンネル・手動調整）と、元になった映像の ID だけを持つ。Q の材料（カメラ角度・解像度・fps・関節の信頼度）は、その映像の投球の解析結果から作る
- お手本の選手の身長は、縮尺と cm の指標に使う（分からなければ 188 cm）

## 結果

- 重みの内訳を UI にそのまま表示できるので、利用者が「なぜこの重みか」を確認・調整できる。
- 人気度だけの重み付けと比べた分布の安定性（ブートストラップでの分散）を、検証結果として README に載せる。
