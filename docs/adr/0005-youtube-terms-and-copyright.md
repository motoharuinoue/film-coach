# ADR-0005: YouTube の規約と著作権への対応

- 状態：提案（利用者の確認待ち）
- 日付：2026-10-05

## 背景

お手本ライブラリと YouTube URL 入力のために、YouTube の動画を解析したい。ただし、YouTube の利用規約は、YouTube が用意したダウンロード手段以外での取得を原則として認めていない。また、動画には投稿者の著作権がある。

## 決定

| 項目 | 方針 |
|---|---|
| 検索・情報取得 | 公式の YouTube Data API v3 を使う |
| 動画の取得 | 個人の手元での解析に限り、指定した区間だけを取得する。取得元は差し替えられる `SourceAdapter` にする |
| 保存 | 元の動画は解析後に削除する。保持するのは骨格・指標などの派生データと、出典（URL・チャンネル・区間）だけ |
| 表示 | お手本の映像は、公式の埋め込みプレイヤー（IFrame Player API）で表示する。動画ファイルは配信しない |
| ライセンス | 「Creative Commons のみ」で絞り込むモードを用意する（検索の `videoLicense=creativeCommon`） |
| 公開デモ | 再生する映像は自分で撮ったものだけ。お手本は埋め込みと骨格だけで見せる |
| API キー | `.env`（git 管理外）か macOS Keychain に保存する。リポジトリやログに出さない |

## 結果

- 動画そのものを再配布しないので、権利面のリスクを抑えられる。
- それでも、規約上グレーな部分（区間の取得）は残る。初期設定を「Creative Commons のみ」にするかは利用者が決める。
