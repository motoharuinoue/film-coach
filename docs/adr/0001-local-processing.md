# ADR-0001: 重い処理はローカル Mac で動かす

- 状態：採用
- 日付：2026-10-05

## 背景

物体検出・骨格推定・セグメンテーションは GPU を使う重い処理。有料サーバーは借りない前提で、次の 3 案があった。

| 案 | 長所 | 短所 |
|---|---|---|
| ローカル Mac + Python | 高精度なモデル（rtmlib、SAM 2）を使える。映像が外に出ない | 他の人がそのまま動かすには環境構築が要る |
| ブラウザだけで完結 | 無料で公開でき、手軽 | 使えるモデルが限られ、精度と機能が落ちる |
| Google Colab + 静的な画面 | 無料 GPU が使える | 解析のたびに手作業が増える |

## 決定

ローカル Mac（Apple M4 / 32GB）で Python の解析サービスを動かす。

## 結果

- 映像を外部に送らずに済むので、プライバシー面で説明しやすい。
- 他の人に見てもらう手段として、解析済み JSON だけで動く公開デモ（GitHub Pages）を別に用意する（[ADR-0004](0004-schema-driven.md)）。
